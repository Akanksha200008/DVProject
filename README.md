# 🎓 Engineering Placements Analysis Through Data Visualization

An analytical project aimed at understanding the key factors that influence engineering student placement outcomes, using data visualization techniques.

---

## 📌 Project Overview

This project analyzes engineering student placement data from a university's on-campus records for the years **2013 and 2014**. The goal is to examine how features like **stream, internships, CGPA, and academic history** impact placement results.

By exploring this data visually, the project supports **students, universities, and recruiters** in making informed decisions regarding hiring, training, and academic planning.

---

## 🗂️ Dataset Overview

- **Source:** [Kaggle - Engineering Placements Prediction Dataset](https://www.kaggle.com/datasets/tejashvi14/engineering-placements-prediction/data)
- **Size:** ~10KB
- **Features Used:**
  - `Age`: Age of the student
  - `Gender`: Male, Female, or Other
  - `Stream`: CSE, ECE, IT, MECH, CIVIL
  - `Internships`: Number of internships completed
  - `CGPA`: Cumulative Grade Point Average
  - `Hostel`: 1 (Yes) or 0 (No)
  - `History of Backlogs`: Number of academic backlogs
  - `Placed`: 1 (Placed), 0 (Not Placed)

---

## 🎯 Objectives

- **What?** Analyze placement data to determine the most influential factors in student placement outcomes.
- **Why?** Help stakeholders (students, universities, recruiters) improve placement strategies and decision-making.
- **How?** Use data visualization to reveal patterns, correlations, and insights from historical placement data.

---

## 📊 Visualizations

1. **Bar Chart – Placement Status by Stream**
   - Compares placement success rates across engineering disciplines.
   - Helps identify streams with higher or lower placement percentages.

2. **Area Chart – Internships vs. Placements**
   - Shows how the number of internships correlates with placement outcomes.
   - Useful to understand how hands-on experience affects employability by stream.

3. **Gauge Chart – Overall Placement Percentage**
   - Displays total percentage of students placed.
   - Provides a quick summary of overall performance.

4. **Dashboard**
   - Combines multiple visualizations into one interface.
   - Helps decision-makers explore placement patterns interactively.

---

## 🛠️ Technologies Used

- **Python**
- **Pandas** – Data manipulation and analysis
- **Matplotlib / Plotly / Seaborn** – Visualization
- **Jupyter Notebook** – Interactive development

---

## 📈 Key Insights

- Streams like CSE and IT generally had higher placement rates.
- Students with more internships showed significantly better placement outcomes.
- CGPA and backlog history also played a notable role in predicting placement success.

---

## ✅ Conclusion

This project reveals that **placement outcomes are influenced by a combination of academic performance, practical experience, and discipline of study**. It provides a solid foundation for future work, such as:
- Building predictive models
- Conducting year-wise trend analysis
- Developing academic strategies for better placements
